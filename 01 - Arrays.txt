Investigación:
Las funciones de arreglos en js permiten crear, añadir, borrar, modificar y, en generar, gestionar los datos que se encuentran
dentro de un arreglo.
Se pueden dividir de la siguiente forma:
    Metodos estaticos:
        Son funciones utilitarias que se llaman directamente desde el objeto global "Array". Estos metodos son:
        Array.from(): Crea un arreglo a partir de un objeto iterable o similar a un arreglo.
            console.log(Array.from("HOLA MUNDO"))
            // ['H', 'O', 'L', 'A', ' ', 'M', 'U', 'N', 'D', 'O']
        Array.isArray(): Comprueba si el objeto que se le está dando es un arreglo o no. Es de tipo booleana.
            console.log(Array.isArray([1, 2, 3]))
            // true
            console.log(Array.isArray(1, 2, 3))
            // false
        Array.of(): Crea un arreglo nuevo con la cantidad de argumentos que se le proporcionen. Soluciona un problema que se ve en el ejemplo.
            console.log(Array.of(3))
            // [3]
            console.log(Array(3))
            // [ , , ]
            console.log(Array.of(3,2,1))
            // [3,2,1]
            console.log(Array(3,2,1))
            // [3, 2, 1]
            Como se puede ver, soluciona el problema que ocurre al poner un numero como argumento en el arreglo, ya que 
            el constructor Array(3) crea un arreglo vacio con 3 espacios, pero Array.of(3) crea un arreglo con un unico dato, viendose así: [3]
    Metodos de instancia
    Vamos a usar los siguientes arreglos para los ejemplos:
    
    // const Array1 = [5, 12, 8, 130, 44, "Hola Mundo"]
    // const Array2 = [4, 4, 2, 4, 2, 3, 1]
    // const Array3 = [0, 1, 2, [3, 4, 5]]
    
    --- Busqueda y acceso a elementos
        Array.at(posicion): Recibe una posicion en un arreglo y retorna el valor que se encuentre en esa posicion del arreglo.
            console.log(Array1.at(2))
            // 8
            console.log(Array1.at(-1))
            // Hola Mundo
        Array.find(callback): Devuelve el primer elemento en el orden del arreglo que cumpla con la condición devuelta por 
        la función/desigualdad de prueba. Si ninguno cumple, retorna "undefined".
            console.log(Array1.find(x => x > 12))
            // 130
        Array.findIndex(callback): Devuelve el índice del primer elemento en el orden del arreglo que cumpla con la condición.
        Si ningún elemento la cumple, retorna "-1".
            console.log(Array1.findIndex(x => x>12))
            // 3
        Array.findLast(callback): Recorre el arreglo de derecha a izquierda y devuelve el primer elemento en el orden del arreglo
        que cumpla con la condición. Si ninguno cumple, retorna "undefined".
            console.log(Array1.findLast(x => x > 12))
            // 44
        Array.findLastIndex(callback): Recorre de derecha a izquierda y devuelve el índice del primer elemento en el orden del arreglo 
        que cumpla con la condición. Si ningún elemento la cumple, retorna "-1".
            console.log(Array1.findLastIndex(x => x > 12))
            // 4
        Array.includes(valor): Determina si el arreglo contiene un elemento determinado. Devuelve "true" o "false".
            console.log(Array1.includes(12))
            // true
            console.log(Array1.includes(6))
            // false
        Array.indexOf(valor): Devuelve el primer índice en el que se encuentra el valor buscado. Retorna "-1" si no existe.
            console.log(Array2.indexOf(2))
            // 2
            console.log(Array2.indexOf(12))
            // -1
        Array.lastIndexOf(): Devuelve el último índice en el que se encuentra el valor buscado (buscando de derecha a izquierda).
        Retorna "-1" si no existe.
            console.log(Array2.lastIndexOf(2))
            // 4
            console.log(Array2.lastIndexOf(6))
            // -1
        

    --- Transformación y creación de nuevos arreglos
        Array.concat(Array2): Concatena o une dos o mas arreglos
            console.log(Array1.concat(Array2))
            // [5, 12, 8, 130, 44, "Hola Mundo", 4, 4, 2, 4, 2, 3, 1]
        Array.filter(callback): Crea un nuevo arreglo con todos los elementos que pasen la prueba de la función proporcionada.
            console.log(Array1.filter(x => x > 9))
            // [12, 130, 44]
        Array.flat(depth): Aplana sub-arreglos anidados hasta el nivel de profundidad especificado (por defecto 1).
            console.log(Array3.flat(1))
            // [0, 1, 2, 3, 4, 5]
        Array.map(callback): Crea un nuevo arreglo con los resultados de aplicar la función proporcionada a cada elemento.
            console.log(Array2.map(x => x*2))
            // [8, 8, 4, 8, 4, 6, 2]
        Array.flatMap(callback): Aplica una función de mapeo a cada elemento y luego aplana el resultado 1 nivel 
        (equivale a .map().flat(1)). Sirve para reemplazar algun numero del arreglo por un arreglo y despues se aplana.
            console.log(Array2.flatMap(x => x === 4 ? [1, 0]: x))
            // [1, 0, 1, 0, 2, 1, 0, 2, 3, 1]
        Array.slice(start, end): Devuelve una copia superficial (shallow copy) de una sección del arreglo definida entre los
        índices start y end (no incluyente (no incluye el ultimo valor)). Lo hace en el orden del arreglo.
            console.log(Array2.slice(2,4))
            // [2, 4]

    --- Modificación de elementos (Estos metodos modifican el arreglo original)
        Array.copyWithin(target, start, end): Copia uno o varios elementos desde su posicion a otra. Es no incluyente
            console.log(Array2.copyWithin(0, 4, 6))
            // [2, 3, 2, 4, 2, 3, 1]
        Array.fill(value, start, end): Rellena todos los elementos (o un rango definido) del arreglo con un valor estático.
            console.log(Array2.fill("C",3,7))
            // [4, 4, 2, 'C', 'C', 'C', 'C']
        Array.pop(): Elimina el último elemento del arreglo y lo devuelve.
            console.log(Array2.pop())
            // 1
        Array.push(...items): Añade uno o más elementos al final del arreglo y devuelve la nueva longitud.
            console.log(Array2.push(3, 7, 0))
            // 10
        Array.reverse(): Invierte el orden de los elementos del arreglo en su lugar (in-place).
            console.log(Array1.reverse())
            // ['Hola Mundo', 44, 130, 8, 12, 5]
        Array.shift(): Elimina el primer elemento del arreglo y lo devuelve.
            console.log(Array1.shift())
            // 5
        Array.sort(compareFunction): Ordena los elementos del arreglo en su lugar y devuelve el arreglo ordenado.
            console.log(Array2.sort())
            // [1, 2, 2, 3, 4, 4, 4]
        Array.splice(start, deleteCount, ...items): Cambia el contenido de un arreglo eliminando, reemplazando o
        agregando elementos en cualquier posición. Devuelve los elementos eliminados.
            console.log(Array1.splice(2, 1, 12))
            // [8]
        Array.unshift(...items): Añade uno o más elementos al inicio del arreglo y devuelve la nueva longitud.
            console.log(Array3.unshift([10, 9, 8]))
            // 5

    --- Alternativas inmutables de modificación (Copian el arreglo)
        Estos metodos son las versiones "seguras" de los metodos que mutan el arreglo original (reverse, sort, splice, etc).
        En vez de modificar el arreglo original, devuelven uno nuevo y dejan el original intacto.
        Array.toReversed(): Devuelve un nuevo arreglo con los elementos invertidos (equivalente inmutable a reverse()).
            console.log(Array2.toReversed())
            // [1, 3, 2, 4, 2, 4, 4]
            console.log(Array2)
            // [4, 4, 2, 4, 2, 3, 1]  (el original no cambia)
        Array.toSorted(compareFn): Devuelve un nuevo arreglo con los elementos ordenados (equivalente inmutable a sort()).
            console.log(Array2.toSorted())
            // [1, 2, 2, 3, 4, 4, 4]
        Array.toSpliced(start, deleteCount, ...items): Devuelve un nuevo arreglo tras eliminar/agregar elementos en un índice
        (equivalente inmutable a splice()).
            console.log(Array1.toSpliced(2, 1, 12))
            // [5, 12, 12, 130, 44, "Hola Mundo"]
        Array.with(index, value): Devuelve un nuevo arreglo cambiando únicamente el valor situado en el índice especificado.
            console.log(Array2.with(2, 99))
            // [4, 4, 99, 4, 2, 3, 1]

    --- Comprobación y evaluación (Booleans y Acumuladores)
        Array.every(callback): Devuelve "true" si todos los elementos del arreglo cumplen la condición dada; de lo contrario, "false".
            console.log(Array2.every(x => x > 0))
            // true
            console.log(Array2.every(x => x > 2))
            // false
        Array.some(callback): Devuelve "true" si al menos uno de los elementos cumple la condición dada.
            console.log(Array1.some(x => typeof x === "number" && x > 100))
            // true
        Array.reduce(callback, initialValue): Ejecuta una función reductora sobre cada elemento (de izquierda a derecha)
        para acumularlo en un único valor.
            console.log(Array2.reduce((acc, x) => acc + x, 0))
            // 20
        Array.reduceRight(callback, initialValue): Igual que reduce(), pero procesa los elementos de derecha a izquierda.
            console.log(Array2.reduceRight((acc, x) => acc + x, 0))
            // 20  (con una suma el resultado es igual, la diferencia se nota con operaciones que no son conmutativas)

    --- Iteración y recorrido
        Array.forEach(callback): Ejecuta la función proporcionada una vez por cada elemento. No devuelve nada (undefined).
            Array2.forEach(x => console.log(x * 2))
            // 8
            // 8
            // 4
            // 8
            // 4
            // 6
            // 2
        Array.entries(): Devuelve un objeto Iterator con pares clave/valor [índice, valor] para cada posición del arreglo.
            console.log([...Array2.entries()])
            // [[0,4], [1,4], [2,2], [3,4], [4,2], [5,3], [6,1]]
        Array.keys(): Devuelve un objeto Iterator con los índices (claves) de cada posición del arreglo.
            console.log([...Array2.keys()])
            // [0, 1, 2, 3, 4, 5, 6]
        Array.values(): Devuelve un objeto Iterator con los valores de cada posición del arreglo.
            console.log([...Array2.values()])
            // [4, 4, 2, 4, 2, 3, 1]
        Array[@@iterator](): Es la función iteradora por defecto del prototipo (alias de values()). Permite que el arreglo
        se pueda recorrer con sintaxis como for...of o la propagación [...arr].
            console.log([...Array2])
            // [4, 4, 2, 4, 2, 3, 1]

    --- Conversión a texto
        Array.join(separator): Une todos los elementos en un string concatenado mediante el separador especificado (por defecto coma ",").
            console.log(Array1.join())
            // "5,12,8,130,44,Hola Mundo"
            console.log(Array2.join("-"))
            // "4-4-2-4-2-3-1"
        Array.toString(): Convierte el arreglo a un string de elementos separados por comas.
            console.log(Array1.toString())
            // "5,12,8,130,44,Hola Mundo"
        Array.toLocaleString(locales, options): Convierte los elementos a cadenas de texto respetando la configuración
        regional especificada (monedas, fechas, números).
            console.log([1000, 2000].toLocaleString("es-CO"))
            // "1.000,2.000"
